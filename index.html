🧠 What Is MindShield?

AI makes it easy to ask for an answer before you've had a chance to think about the problem yourself. MindShield adds a small amount of friction to those moments.

Instead of blocking AI, it asks: "Do you actually need AI for this?"

The goal isn’t less AI. It’s more intentional AI use. Simple shortcut requests trigger a brief reflection pause, while substantial requests pass through immediately.

⚡ How It Works

Step 1

Write Prompt

Use ChatGPT, Claude, Gemini, or Grok normally in your browser.

Step 2

Local Check

An on-device model checks whether your request is a simple shortcut or real work.

Step 3

Pause or Pass

Shortcuts trigger a reflection period. Substantial tasks submit immediately.

🎯 Designed For Better Thinking

Adds Reflection Pause
  • Simple calculations (e.g. 15 * 42)
  • Basic trivia you easily remember
  • Making quick social decisions for you
  • Shortcuts before trying to solve it
Passes Immediately
  • Deep research & learning
  • Code debugging & architecture
  • Complex problem solving
  • Long-form content drafting

🌐 Supported Platforms & Privacy

ChatGPT Claude Google Gemini Grok

🔒 100% On-Device & Private: MindShield performs prompt evaluation locally using a WebAssembly machine-learning model (DistilBERT-MNLI). Your prompts are never sent to an external server. No tracking, no analytics, no cloud prompt analysis.

📥 Install MindShield

🦊 Add to Firefox 🌐 Chrome v1.2.0 ZIP

Chrome / Chromium Installation:

  1. Download the ZIP from the v1.2.0 release and extract it.
  2. Open chrome://extensions/ in your browser.
  3. Enable Developer mode (top right).
  4. Click Load unpacked and select the extracted MindShield folder.
